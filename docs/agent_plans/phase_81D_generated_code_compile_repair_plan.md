## Phase title

Repair generated C++ compile errors in exported VisiForm projects.

## Current state

- A project generated by VisiForm fails to compile in Visual Studio.
- Reported errors include:
  - generated files start with `Generated by VisiForm 1.0.0.` as code instead of a comment
  - generated `MainWindow` declares `mouseDoubleClick(...) override`, but the current Visage API does not provide that virtual override
  - generated `MainWindow.cpp` contains a duplicate `case RuntimeWidgetType::TableGrid`

## Goal

Fix the code generator so freshly exported projects produce valid C++ for the current Visage API.

## Files inspected

- `src/generator/VisageCppEmitter.cpp`
- generated output under `Generated/` was inspected only as a reference
- local Visage headers under the build dependency tree were inspected only to confirm mouse event API shape
