# Versioning

## Current version

Current `VisiForm` version: `1.0.17`

## Primary version sources

Repository version metadata is currently defined in two places:

- root `CMakeLists.txt`
  - `project(VisiForm VERSION 1.0.17 LANGUAGES CXX)`
- `src/app/Version.h`
  - `visiform::VersionMajor`
  - `visiform::VersionMinor`
  - `visiform::VersionPatch`
  - `visiform::VersionString`
  - `visiform::BuildName`
  - `visiform::WindowTitle`

## UI behavior

Current UI version presentation:

- the main editor window title uses `visiform::makeWindowTitle(...)`
- the dirty marker remains appended as `*`
- `Help > About VisiForm` uses `visiform::aboutDialogText()`
- the About dialog shows the product name, version, description, and current `Debug` or `Release` build configuration

## Generated code comment behavior

Generated source files currently include a versioned header comment built from `visiform::generatedByComment()`.
This produces text such as:

- `Generated by VisiForm 1.0.17`

## How to bump the version later

When updating the app version:

1. Update the root `CMakeLists.txt` project version.
2. Update the constants in `src/app/Version.h`.
3. Update any repository-facing version text such as `README.md`.
4. Rebuild with `build-static-debug`.
5. Review the main window title, About dialog, and generated source header comment output for consistency.
