## Goal 1: Fix Layout menu text formatting

The Layout menu width is too narrow for the new command labels.

Observed labels include:

- Same Width: Match Primary
- Same Width: Match Smallest
- Same Width: Match Largest
- Same Height: Match Primary
- Same Height: Match Smallest
- Same Height: Match Largest

Required behavior:

- all command text is fully readable
- shortcut text remains aligned in a separate right-side column
- command labels and shortcuts do not overlap
- menu width is based on actual rendered text metrics
- menu width accounts for:
  - longest command label
  - shortcut column
  - left and right padding
  - submenu indicator if used
  - icon/checkmark area if used
- menu height and row spacing remain consistent
- disabled text remains readable
- menu does not become unnecessarily wide

Use actual font metrics.

Do not use a fixed width that only fits the current screenshot.

- Same Width
  - Match Primary
  - Match Smallest
  - Match Largest
- Same Height
  - Match Primary
  - Match Smallest
  - Match Largest

If submenus are already implemented and working, preserve them.

If the current menu system is using flat commands, keep the existing structure for this pass and correct the width calculation rather than redesigning the menu.

## Goal 3: Fix startup and New Project placement at the model source

The default Button must be fully inside the top-level form immediately after project creation.

Requirements:

- use form-local model coordinates
- do not use canvas viewport coordinates
- do not depend on zoom, pan, splitter positions, or window size
- do not place using form bounds that are still zero or uninitialized
- ensure the default form size is established before calculating child placement
- use the shared safe-placement helper where appropriate
- remove or replace any old hard-coded placement path that bypasses the helper
- do not merely clamp drawing while leaving invalid model coordinates

Preferred behavior:

- use a modest inset from the form’s top-left content area
- place the complete default Button inside the form
- produce identical valid results at startup and through New Project
