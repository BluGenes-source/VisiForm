The `Multiline` property cannot be changed in the Property Inspector.

Observed behavior:

* the row displays `Multiline (Inh)`
* the status hint says it is inherited from normal widget Appearance
* the Boolean editor does not allow selecting `true`
* `Multiline` is a normal Text Box behavior property and must not use Appearance inheritance

## Goal 3: Correct `Multiline` semantics

`Multiline` must be a direct Boolean Text Box property.

Required behavior:

* label displays `Multiline`, without `(Inh)`
* editor offers `false` and `true`
* selecting a value commits immediately
* the Text Box model updates
* the project becomes dirty only when the value changes
* undo and redo work
* the widget repaints
* save/load preserves the value
* the hint describes multiline behavior, not Appearance inheritance

Suggested hint:

`Allows the Text Box to contain and edit multiple lines.`

Use existing project wording conventions.
