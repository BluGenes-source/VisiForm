Act as the lead agent for the VisiForm repository.

Investigate and, only if reproduced, fix the following possible sizer resizing

## Reported behavior

### Issue 1: Child widget resize becomes locked

When a Button is dropped into a sizer:

1. The Button can initially be resized by changing its height.
2. After the user releases the resize drag, the Button cannot be resized again.
3. Its width and height appear to become locked.

The exact behavior may depend on sizer flags, layout constraints, selection
state, or designer resize-handle state.

### Issue 2: Sizer children do not resize with the sizer

When a sizer containing widgets is resized, the widgets inside the sizer do not
resize or relayout as expected.

The phrase “resizing a resizer” in the original report should be interpreted as
“resizing a sizer” unless repository terminology shows that a separate Resizer
component exists.
