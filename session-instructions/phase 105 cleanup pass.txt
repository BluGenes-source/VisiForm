## Required label policy

Internal widget names are editor metadata.

Examples:

* `button1`
* `slider1`
* `textBox1`
* `checkBox1`
* `comboBox1`

They may be used for:

* Project Tree labels
* Property Inspector Name fields
* generated variable or member identifiers
* optional Design Mode identification aids

They must not be rendered as visible runtime content in:

* Preview Mode
* exported applications

Only explicit user-facing properties may appear at runtime.

Examples include:

* Button Text
* Label Text
* Check Box caption
* Combo Box selected value
* Text Box text or placeholder
* Group Box caption
* Frame title
* Window title
* explicit Slider value text, only if such a property exists

Do not infer runtime text from the widget Name property.

* `shouldDrawEditorLabel()`

## Goal 4: Preserve legitimate runtime text

Do not hide actual user-facing text.

Examples:

* `Button` on a Button must remain visible.
* `CheckBox` caption must remain visible.
* Combo Box content such as `Apple` must remain visible.
* Frame or Group Box titles must remain visible.
* Label widgets must continue to render their Text property.
* Text Box content must remain visible.
* Window titles must remain visible where appropriate.

Use the correct explicit property for each widget.

Do not substitute the internal Name when a user-facing property is empty.

An empty user-facing Text or Caption property should normally render no text.
